# วางไฟล์เสียงที่นี่

โฟลเดอร์นี้ประกาศไว้ใน `pubspec.yaml` แล้ว (เป็นโฟลเดอร์ ไม่ใช่ไฟล์เดี่ยว) วางไฟล์ชื่อตรงตามนี้ได้เลย
ไม่ต้องแก้ `pubspec.yaml`/โค้ดเพิ่ม — `lib/services/sound_service.dart` เรียกใช้ 5 ชื่อนี้ตรงๆ
(⚠️ ตัวพิมพ์เล็ก-ใหญ่ของนามสกุลไฟล์ต้องตรงเป๊ะ — Android build สนใจตัวพิมพ์เล็ก-ใหญ่ ต่างจาก Windows):

- `background_music.mp3` — เพลงพื้นหลัง เล่นวนตั้งแต่เปิดแอพ
- `button_click.mp3` — เสียงกดปุ่ม เล่นทุกครั้งที่แตะ widget ที่กดได้จริง
- `buy_success.mp3` — ซื้อของ/ซื้อ upgrade สำเร็จ (หน้า Shop และหน้า Profile ส่วน Upgrade Ability)
- `notification.MP3` — มีแจ้งเตือนใหม่โผล่เข้ามา (เทียบ id เดิม/ใหม่ใน `NotificationProvider` — ไม่เล่น
  ตอนโหลดครั้งแรกสุดตอนเปิดแอพ เพราะนั่นคือแจ้งเตือนเก่า ไม่ใช่ของใหม่)
- `quess_success.MP3` — ทำเควสสำเร็จ (เรียกจาก `lib/utils/quest_completion.dart` จุดเดียว ใช้ร่วมกันทั้ง
  4 ที่ที่ทำเควสได้)

เสียงเอฟเฟค 4 อย่างหลัง (ทุกอย่างยกเว้นเพลงพื้นหลัง) ใช้ระดับเสียงเดียวกับสไลเดอร์ "Sound Effects" ใน
หน้า Settings ไม่มีของตัวเอง

ไม่มีไฟล์ก็รันแอพได้ปกติ (แค่ไม่มีเสียง) — `SoundService` ดัก error ไว้ให้แล้วไม่ทำให้แอพพัง
