# วางไฟล์เสียงที่นี่

โฟลเดอร์นี้ประกาศไว้ใน `pubspec.yaml` แล้ว (เป็นโฟลเดอร์ ไม่ใช่ไฟล์เดี่ยว) วางไฟล์ชื่อตรงตามนี้ได้เลย
ไม่ต้องแก้ `pubspec.yaml`/โค้ดเพิ่ม — `lib/services/sound_service.dart` เรียกใช้ 2 ชื่อนี้ตรงๆ:

- `background_music.mp3` — เพลงพื้นหลัง เล่นวนตั้งแต่เปิดแอพ
- `button_click.mp3` — เสียงกดปุ่ม เล่นทุกครั้งที่แตะหน้าจอ

ไม่มีไฟล์ก็รันแอพได้ปกติ (แค่ไม่มีเสียง) — `SoundService` ดัก error ไว้ให้แล้วไม่ทำให้แอพพัง
